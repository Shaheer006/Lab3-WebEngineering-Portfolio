# Personal Portfolio Website

* Author: Shaheer Ahmed Qaiser
* Project: A basic personal portfolio website created for a lab assignment.

Technologies Used

* HTML5: Used for the core structure and semantic layout of all pages.
* CSS3: Used for styling, flexbox layouts, float-based grids, and an interactive JS-free fullscreen image modal using the `:target` pseudo-class.

Page Structure

* Home (`index.html`): Features a hero section with a brief introduction and an overview of current learning goals.
* Hobbies (`hobbies.html`): Displays personal interests like sim racing, motorsports, and tech, along with a mini image gallery.
* Skills (`skills.html`): Lists programming languages (HTML, CSS, JS, C++, etc.), tools, and spoken languages.
* Gallery (`gallery.html`): Contains a 3-column by 2-row image grid with click-to-view fullscreen functionality.
* Contact (`contact.html`): Provides direct contact details including email, phone number, and GitHub profile.
